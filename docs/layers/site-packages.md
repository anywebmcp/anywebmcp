# Site packages layer

`packages/sites/*` contains one package per supported website. A site package can expose different WebMCP tool sets for different areas of the same website based on the current URL.

Each package owns:

- Domain match patterns.
- Path match patterns that determine which WebMCP tools are available for the current URL.
- WebMCP tool definitions.
- Page context and selectors.
- UI, official API, or internal API adapters.

## Package structure

```text
packages/sites/<site>/
  README.md       Site-specific documentation
  package.json    Package metadata and dependencies
  src/
    index.ts      Site manifest and package entry point
    tools/        WebMCP tool definitions
    api/          Optional website API adapters
```

A package can add other directories under `src` when its implementation requires them. Its `README.md` is the source of truth for supported domains and paths, available tools, implementation details, setup, and site-specific limitations.
